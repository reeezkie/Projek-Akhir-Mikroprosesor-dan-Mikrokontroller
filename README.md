# Projek-Akhir-Mikroprosesor-dan-Mikrokontroller
Merancang sistem deteksi kebakaran dan suhu menggunakan sensor, mengembangkan kode program mikrokontroler, serta mengintegrasikan seluruh komponen perangkat keras dan perangkat lunak untuk menghasilkan sistem deteksi dini yang berfungsi sesuai kebutuhan.
